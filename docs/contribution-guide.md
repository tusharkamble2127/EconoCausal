# EconoCausal — Contribution Guide

## Team Rules

1. The `main` branch contains reviewed and accepted code.
2. Every task must be developed on a separate feature branch.
3. Direct pushes to `main` are not allowed.
4. Every change must be submitted through a Pull Request.
5. PR descriptions must explain the changes and include testing details.
6. Commit messages must clearly describe the changes.
7. Never commit `.env` files, passwords, API keys, private data, or credentials.
8. Resolve merge conflicts carefully and test changes before merging.

## Branch Naming

- `feature/dataset-eda`
- `feature/causal-graph`
- `feature/react-dashboard`
- `feature/budget-ui`

## Commit Naming

Use prefixes such as `feat:`, `fix:`, `docs:`, `test:`, and `refactor:`.

## Review Process

The repository owner reviews each PR, requests changes if necessary, and merges approved changes into `main`.
