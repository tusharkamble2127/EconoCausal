# EconoCausal 
 
About: 

EconoCausal Frontend is the interactive web interface for the EconoCausal platform — a causal inference and uplift modeling analytics system designed to help businesses identify which customers are most likely to respond positively to targeted marketing treatments.

The frontend transforms complex causal-analysis outputs into an intuitive analytics experience with:

📊 Interactive dashboards,
👥 Customer-level recommendations,
📈 Uplift analysis,
📉 Qini analysis,
💰 Revenue and ROI insights,
🎯 Customer segmentation,
📂 Campaign data upload,
🔎 Recommendation filtering and search,
⚡ Real-time interface updates

The frontend presents these causal insights in a business-friendly format so users can move from:

Customer Data
      ↓
Causal Analysis
      ↓
Uplift Estimation
      ↓
Customer Segmentation
      ↓
Treatment Recommendation
      ↓
Business Decision
